# Contributing to BM Business Stock Management

Thank you for considering contributing to our project! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/BM-Business-Stock-Management.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit: `git commit -m 'Add your feature'`
6. Push: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Code Style

- Follow C# naming conventions (PascalCase for public members)
- Use XAML for UI
- Keep methods small and focused
- Write XML documentation comments
- Use async/await for I/O operations

## Reporting Issues

- Use GitHub Issues
- Provide a clear description
- Include steps to reproduce
- Attach screenshots/logs if relevant

## Pull Request Process

1. Update README.md if needed
2. Add tests for new features
3. Ensure all tests pass
4. Request review from maintainers

## Questions?

Feel free to open a discussion on GitHub!
